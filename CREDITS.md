# Credits

Royalty Fusion DIAN PHP is the work of the Royalty Fusion team, but it stands
on the shoulders of the giants of the Colombian electronic-invoicing
open-source ecosystem. We are grateful for every line of reference code that
helped us validate our implementation against real DIAN behaviour.

## Inspiration

* **[Greenter](https://github.com/giansalex/greenter)** (MIT) by Giancarlos
  Salas. The whole architecture of this SDK — Twig templates, Greenter-style
  `See::send()` facade, model objects with fluent setters, the
  separation between `Xml`, `Signer`, `Ws`, `Validator`, `Report` and
  `Bridge/Symfony` — is a direct homage to the way Greenter organises a
  national-level electronic-invoicing SDK in PHP. We did not copy code; we
  copied the *idea* of how a great DIAN SDK should look from afar.

## Reference implementations consulted

The following projects served as production-validated references when
implementing pieces of the DIAN spec that the official Anexo Técnico V1.9
leaves ambiguous (byte-level reference order in XAdES, WS-Security envelope
shape, payroll concatenation strings, etc.):

* **[lopezsoft/ubl21dian](https://github.com/lopezsoft/ubl21dian)** (MIT) by
  Lewis Lopez. We studied the constants, namespace URIs, ID prefixes and
  the *order* of `<ds:Reference>` blocks in their `SignAttachedDocument`,
  `SignDocumentSupport`, `SignEvent`, `SignPayroll` and
  `BinarySecurityToken/SOAP` modules. Our equivalents are written from
  scratch in our Twig/Signer architecture but follow the same algorithmic
  recipe, which is what DIAN actually validates byte-for-byte.

* **[Stenfrank/ubl21dian](https://github.com/Stenfrank/ubl21dian)** by
  Stenfrank — the OG Colombian XAdES PHP SDK. Used as a sanity check for
  the base `SignInvoice` flow.

## Production fixtures

* **Siigo Nube** — the AttachedDocument XML at
  `resources/fixtures/siigo-blindacces-FV5.xml` is a real DIAN-approved
  invoice generated by Siigo for BLINDACCES SAS. Used as the canonical
  golden master in `tests/Unit/AttachedDocument/AttachedDocumentParserTest`.
